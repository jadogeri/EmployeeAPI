# Support

Thank you for using **EmployeeAPI**! Here are the ways to get help.

---

## 📖 Documentation

Before opening an issue, please check the following resources:

- **[README](./README.md)** — Installation, setup, endpoint reference, and project structure
- **Swagger UI** — Interactive API docs at `http://localhost:8000/docs` when the server is running
- **ReDoc** — Alternative API docs at `http://localhost:8000/redoc`

---

## 🐛 Found a Bug?

If you've found a bug, please [open a GitHub issue](https://github.com/jadogeri/EmployeeAPI/issues/new?template=bug_report.md) using the **Bug Report** template.

Please include:
- Steps to reproduce
- Expected vs. actual behavior
- Your Python version and operating system
- Relevant logs or tracebacks

---

## 💡 Have a Feature Request?

If you have an idea for an improvement, please [open a GitHub issue](https://github.com/jadogeri/EmployeeAPI/issues/new?template=feature_request.md) using the **Feature Request** template.

---

## 💬 General Questions

For general questions about usage or the project architecture, please [open a GitHub Discussion](https://github.com/jadogeri/EmployeeAPI/discussions) rather than an issue. This keeps the issue tracker focused on bugs and feature requests.

---

## 📬 Contact

For anything not covered above, you can reach the maintainer directly:
